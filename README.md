
# Diego Rivera — Portafolio

Portafolio profesional de Diego Rivera, desarrollador de software especializado en aplicaciones web y soluciones empresariales.

## Tecnologías

- Next.js 16
- React 19
- TypeScript
- CSS Modules

## Desarrollo local

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor:

```bash
npm run dev
```

Abrir http://localhost:3000
